# Volley Stats Live

Necesito una aplicación para gestionar estadísticas de vóley en tiempo real.

Antes del partido se cargan los equipos, jugadores y la formación inicial.

Durante el partido, cada vez que se hace un punto, se registra:

Qué equipo hizo el punto.

Qué jugador participó.

Cómo se consiguió el punto:

Ataque.

Bloqueo.

Ace de saque.

Error no forzado del rival.

También debe permitir registrar cambios de jugadores y tiempos muertos.

Al finalizar el partido, el sistema debe generar automáticamente estadísticas individuales y de equipo, como:

Puntos por jugador.

Puntos por ataque.

Puntos por bloqueo.

Puntos por saque.

Errores no forzados.

Máximo anotador del partido.

Además, debe mostrar resultados, fixture y tablas de posiciones de la liga.

En una sola frase:

Una plataforma para ligas de vóley que permita cargar partidos en vivo, registrar quién hizo cada punto y cómo lo hizo, y generar estadísticas automáticas de jugadores, equipos y torneos.
