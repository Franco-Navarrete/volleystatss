# Enlaces para logos de equipos

## Objetivo
Permitir pegar una URL de imagen como logo al crear o editar un equipo, conservando la opción actual de subir un archivo.

## Cambios
- Agregar un campo “Link del logo” en el formulario de nuevo equipo.
- Mostrar una vista previa del enlace antes de guardar.
- Agregar el mismo campo al editar un equipo existente.
- Validar que el valor sea una URL `http` o `https`; permitir borrar el logo.
- Mantener intacta la carga de imágenes desde el dispositivo.
- Verificar creación, edición, vista previa y persistencia del logo.
